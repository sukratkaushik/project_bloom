2. Deep-Dive Findings

Dimension 1: Static Analysis & TypeScript

  • Standard Mode: npm run lint (tsc --noEmit) passes with 0 errors.
  • Strict Mode: 9 errors detected: 7 missing @types/react-dom declarations for createPortal and createRoot, union parameter id in PartnerSync.tsx, and dueDate null vs undefined in PregnancyTracker.tsx.

Dimension 2: Database & Dexie.js Data Integrity

  • IndexedDB Architecture: Clean incremental schema migrations (v1–v4) with compound query indexes for live reactivity.
  • DPDP Right to Erasure: Account deletion executes dexieDb.tables.map(t => t.clear()) and deletes local database files.
  • ⚠️ CloudSync Hook Discrepancy: db.contractionSessions is hooked for cloud sync, but individual db.contractionRecords are not hooked, causing detailed contraction intervals to be lost on cross-device restore.

Dimension 3: Functional Core Flows

  • Kick Counter: Cardiff "Count to 10" protocol with 2-hour prolonged inactivity warning.
  • Contraction Timer: Accurately computes 5-1-1 rule (frequency ≤ 5m, duration ≥ 60s, pattern ≥ 1h) with direct 108 emergency call prompt. Active timers survive navigation via localStorage.
  • Vitals Tracker: Standard BP classification (Crisis ≥ 160/110, Stage 2 ≥ 140/90) with appropriate non-diagnostic observational phrasing.
  • 2-Tier Architecture: Clean Free Plan vs Bloom Pro gating.

Dimension 4: Android Capacitor Readiness

  • Native Plugins: 7 core plugins verified and synced via npx cap sync android including native Google Auth bridge (@capacitor-firebase/authentication).
  • Manifest & Security: allowBackup="false" and usesCleartextTraffic="false" enforced. Health Connect rationale intents configured.
  • Safe Areas: viewport-fit=cover active in index.html; dynamic safe area padding configured.

Dimension 5: Non-Functional & Performance

  • Offline Functionality: Workbox service worker precaches 33 assets (3.84 MB) with seamless offline IndexedDB fallback.
  • Bundle Size Warning: Entry bundle is 2.76 MB (2,759 kB) uncompressed / 748 kB gzip. Vite reports dynamic vs static import collisions on firebase/functions, pdfExport.ts, and cloudSync.ts.
  • Root Cause: All 34 dashboard tabs in Dashboard.tsx are synchronously imported.

Dimension 6: Clinical & Compliance Safety

  • PCPNDT Act 1994 (Zero-Tolerance): 🟢 Flawless. Cloud Functions employ regex interceptor isPCPNDTGenderQuery to reject gender queries before invoking AI models. Report parser redacts fetal gender terms.
  • Universal Medical Disclaimers: 🟡 Missing mandatory educational disclaimer on 5 tracking screens (Kick Counter, Contraction Timer, Vitals Tracker, Food Scanner, Labor Readiness).
  • DPDP Act 2023: Granular bilingual consent modal properly gated on login/app entry rather than unauthenticated landing page visitors.

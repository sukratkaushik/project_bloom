## How to use

- Read the doc first (`applications/web.md`, `voice/homepage-copy.md`, etc.).
- When you're about to design or write a new asset, **look at the matching screenshot** to sanity-check what actually ships.
- Cite screenshots by filename when explaining a design choice: e.g. *"see `landing-page-hero-section.png` for the current hero layout"*.
- When a new refresh lands, re-capture and replace these files. Update `reconciliation.md` with what changed.
